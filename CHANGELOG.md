# Changelog

## 1.0.0 - 2026-10-09

- Initial release of the animated Contour Flow screensaver for Android API 23 and newer.
- Added three relief shapes, four color palettes, density, movement, line weight, lighting, brightness, and per-setting random choices.
- Added a standalone checksum-verifying installer and a versioned settings provider.
- Runtime makes no network requests and includes no ads, analytics, tracking, or reporting.
