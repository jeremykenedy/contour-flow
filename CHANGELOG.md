# Changelog

## 1.1.0

- Replace the nearly still Canvas scene with continuously evolving native GLES relief and analytic contour antialiasing.
- Preserve all seven settings, random choices, package identity and upgrade signer.
- Use gradient-corrected mesh evaluation on suitable drivers, with the original fragment evaluation fallback and full Android-provided surface size.
- Schedule visible frames with Choreographer and preserve paused scene progress.
- Add a native-derived system preview image and offline credits, notices and license text.
- Refresh native screenshots, motion documentation and integration instructions.

## 1.0.0 - 2026-10-09

- Initial animated Contour Flow screensaver for Android API 23 and newer.
- Three relief shapes, four palettes, density, movement, line weight, lighting, brightness and random choices.
- Standalone checksum-verifying installer and versioned settings provider.
- No runtime network requests, ads, analytics, tracking or reporting.
