# Configuration

Settings are available from the app's Settings screen. Each option can be set to Random. The optional Randomize supported settings action randomizes all seven settings for the next preview or screensaver session. Values resolve once when the scene starts and stay fixed for that session.

| Setting | Options | Default | Effect |
|---|---|---|---|
| Color palette | Abyss, Slate, Sandstone, Glacier | Abyss | Changes the background and contour colors. |
| Landform | Ridges, Basins, Coast | Ridges | Changes the shape and flow of the relief field. |
| Contour density | Sparse, Open, Balanced, Dense, Very dense | Balanced | Changes the number of contour levels. |
| Drift speed | Very slow, Slow, Balanced, Quick, Fast | Balanced | Changes how quickly the relief moves. |
| Line weight | Fine, Light, Balanced, Bold, Heavy | Light | Changes contour stroke width. |
| Lighting | Auto, Day, Night | Auto | Auto follows local device time; Day and Night set the scene treatment. |
| Brightness | Dim, Low, Balanced, Bright, Very bright | Balanced | Adjusts contour and ambient light intensity. |

The renderer uses the display size Android provides. It does not request or force a 4K buffer.
