# Privacy

Contour Flow requests no `INTERNET` permission. The app does not make network requests, collect or report usage or device data, or include ads, analytics, telemetry, crash reporting, tracking identifiers, or remote update checks.

Scene animation and settings are processed locally on the TV. Settings remain in app-private storage. The separate installer downloads an APK only after the user runs it and verifies the supplied SHA-256 checksum.
